## 💡 為什麼選擇 Agent 原生版？

傳統的發票辨識軟體需要安裝複雜的 Python 環境、調校 OpenCV 影像濾鏡、打包肥大的 `.exe` 或 `.app`，且遇到**發票折損、皺褶、反光、手寫二聯/三聯單、二維碼被撕毀**時，傳統解碼引擎往往束手無策。

**AI CPB Agent 採用全新的「Agent 原生（Agent-Native）」架構**：
- 🧠 **多模態視覺直讀**：直接由 Gemini 視覺模型讀圖，辨識率與抗皺褶容錯力達到頂級水準。
- 📜 **純文字 Skill 驅動**：所有專業稅法判定與檔案格式規範全部封裝在純文字 `SKILL.md` 中，沒有任何外部編譯負擔。
- 💬 **互動式 Step-by-Step 審查**：遇到交際應酬、模糊品項，AI 會主動在對話中向您請示確認，落實人機協作（Human-in-the-loop）。
- 📑 **一秒生成財政部標準檔**：產出 100% 符合國稅局 BLR 電子申報系統規格的 81-byte 定寬純文字檔 (`.TXT`) 與核對專用 Excel 清冊。

## 🚀 三分鐘快速上手

### 步驟 1：安裝技能（二選一）

- **方式 A（專案工作區模式，最推薦）**：
  只要直接使用 Gemini / Antigravity 應用程式開啟本 `AI_CPB_Agent` 資料夾作為工作區，系統就會**自動識別並掛載** `.agents/skills/taiwan-invoice-deductor/`，免任何安裝！
- **方式 B（全域安裝，隨處可用）**：
  - **Windows**：雙擊 `install_skill.bat`。
  - **macOS / Linux**：終端機執行 `bash install_skill.sh`。
  *(會自動將技能複製到全域目錄 `~/.gemini/config/skills/`，讓您在電腦上的任何專案都能隨時呼叫)*。

### 步驟 2：放入發票照片

將本期要申報的進項發票圖檔（手機拍照、電子發票證明聯截圖、掃描檔、PDF）集中放入 **`invoices/`** 資料夾。

### 步驟 3：喚醒 AI Agent 互動對話

在對話框中輸入任意一句話：
> **「請幫我處理 invoices 資料夾內的發票」**  
> 或  
> **「辨識本期發票並產出營業稅申報檔」**

AI 就會自動啟動 **Step-by-Step 互動指引**！

## 🤖 Step-by-Step 互動流程展示

### 階段 1：基本參數確認
AI 會主動讀取 `settings.json` 並與您確認：
> **AI**：「已為您確認申報設定：
> - 買方統編：`25094721`
> - 稅籍編號：`080123456`
> - 申報期別：`11510` (115年 9-10 月期)
> 
> 在 `invoices/` 資料夾中發現 5 張發票照片，現在開始進行多模態視覺辨識...」

---

### 階段 2：發票掃描與多模態解析
AI 逐張閱讀發票圖片，擷取：
- 發票字軌號碼（如 `AA-12345678`）
- 開立日期（如 `115/09/20`）
- 賣方統一編號
- 未稅銷售額、營業稅額 (5%)、含稅總額
- 購買品名清單（如「A4影印紙」、「商務午餐會議」、「外送運費」）

---

### 階段 3：《營業稅法》第 19 條扣抵審查與人機疑義提問
AI 依據營業稅法進行扣抵分類：
- **可扣抵進項（格式代號 21 / 扣抵代號 1）**：業務所需支出（文具、運費、電腦設備、辦公室水電）。
- **不得扣抵憑證（格式代號 23 / 扣抵代號 3）**：交際應酬（餐飲、咖啡、茶點、禮盒）、個人消費、自用小客車。

若遇模糊品項，AI 會主動發起確認：
> **AI 提問**：「📌 發票 `AB-87654321`（金額 $3,500）品名為『星巴克咖啡禮盒』：
> 依《營業稅法》第 19 條第 1 項第 3 款，交際應酬餽贈之貨物不得扣抵銷項稅額。我預設將其列為 **『23 不得扣抵』**（營業稅不可扣抵，但保留發票作為年度營所稅費用）。請問是否同意此判定？」

---

### 階段 4：產出成果與報告
確認無誤後，AI 會自動在 `output/` 資料夾產出：
1. **財政部 BLR 申報檔**：`output/25094721.TXT`

## 🏛️ 如何匯入財政部電子申報繳稅系統 (BLR)

1. 開啟財政部【營業稅電子申報繳稅系統】軟體。
2. 進入 **【進項資料】** ➔ **【媒體檔案匯入】**。
3. 檔案類型選擇：`進項 (三聯式、電子發票、收銀機等)`。
4. 瀏覽選取 `output/` 資料夾內的 **`{買方統編}.TXT`**。
5. 點擊「開始轉入」，檢核結果將顯示「**轉入成功，0 筆錯誤**」！

## 🔒 常見問題 (FAQ)

### Q1：發票照片會外洩嗎？
Gemini 本機應用程式（Antigravity）依照 Google 安全與隱私協議執行，產出的 `.TXT` 和 `.xlsx` 申報檔案完全保存在您自己的本機磁碟，不會公開發布。

### Q2：手寫發票或無 QR Code 的舊式二聯收據可以辨識嗎？
可以！這正是多模態大模型相較於傳統 OpenCV 最強大的地方。即使完全沒有 QR Code，AI 依然能直接閱讀發票上的中文大寫數字、印章與手寫字跡。

### Q3：如何修改預設的公司統編與期別？
直接開啟 `settings.json` 修改裡面的三項欄位即可：
```json
{
  "buyer_tax_id": "你的公司統編8碼",
  "tax_register_no": "稅籍編號9碼",
  "period": "申報民國年月5碼(如11510)"
}
```
